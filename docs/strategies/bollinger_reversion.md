# Bollinger Bands Reversion (الارتداد من حزم بولينجر)

**اسم الاستراتيجية في الإعدادات:** `bollinger_reversion`
**النوع:** الارتداد للمتوسط (Mean Reversion)

## الفكرة
حزم بولينجر = 3 خطوط:
- **الوسط:** متوسط بسيط لآخر 20 شمعة.
- **الحزمة العليا / السفلى:** الوسط ± 2 انحراف معياري.

إحصائياً السعر معظم الوقت بيضل جوّا الحزم. لما يطلع تحت الحزمة السفلى معناها نزل بشكل "غير طبيعي" بالنسبة لتقلّبه الأخير، والفرضية إنه رح يرجع للوسط.

بنستنى السعر **يرجع يسكّر جوّا الحزمة** كتأكيد (مش بس يلمسها).

## قواعد الدخول والخروج
| | القاعدة |
|---|---|
| دخول | الشمعة السابقة سكّرت تحت الحزمة السفلى، والحالية سكّرت فوقها (رجعت لجوّا) |
| خروج | السعر يوصل الخط الأوسط (`exit: middle`) أو الحزمة العليا (`exit: upper`) |

## المعاملات
| المعامل | الافتراضي | الشرح |
|---|---|---|
| `period` | 20 | عدد الشموع للمتوسط والانحراف |
| `num_std` | 2.0 | عرض الحزم. أكبر = إشارات أقل وأقوى |
| `exit` | `middle` | `middle` = هدف قريب وصفقات أكثر نجاحاً، `upper` = هدف أبعد |

## متى بتنجح؟
- بالسوق العرضي / المتذبذب ضمن نطاق.
- Win% عالي عادةً.

## متى بتفشل؟
- بالاتجاهات القوية: بالهبوط القوي السعر "بيمشي على الحزمة السفلى" وبيضل ينزل.
- ربح الصفقة صغير (للوسط بس) فالرسوم بتاكل جزء مهم منه.

## إدارة المخاطر المقترحة
`stop_loss_pct: 5` (مفعّل بالإعدادات الافتراضية).

## مثال إعدادات
```yaml
- name: bollinger_reversion_20
  strategy: bollinger_reversion
  params: {period: 20, num_std: 2.0, exit: middle}
  stop_loss_pct: 5
```
