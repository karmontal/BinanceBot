# RSI Mean Reversion (الارتداد بمؤشر القوة النسبية)

**اسم الاستراتيجية في الإعدادات:** `rsi_reversion`
**النوع:** الارتداد للمتوسط (Mean Reversion)

## الفكرة
مؤشر **RSI** بيقيس قوة الصعود مقابل الهبوط بآخر N شمعة، وقيمته بين 0 و 100:
- تحت 30 → السعر نزل كثير وبسرعة (**تشبّع بيعي / Oversold**).
- فوق 70 → السعر طلع كثير وبسرعة (**تشبّع شرائي / Overbought**).

الفرضية: بعد الحركات الحادة السعر غالباً **بيرتد**. فبنشتري بعد الهبوط الحاد وبنبيع بعد الارتداد.

ما منشتري لحظة ما يكون RSI تحت 30 (ممكن يكمّل نزول)، بنستنى **يرجع يطلع فوق 30** كتأكيد إنه الهبوط هدي.

## قواعد الدخول والخروج
| | القاعدة |
|---|---|
| دخول | RSI كان تحت `oversold` بالشمعة السابقة وصار فوقه بالشمعة الحالية |
| خروج | RSI يوصل `overbought` أو أعلى |

## المعاملات
| المعامل | الافتراضي | الشرح |
|---|---|---|
| `period` | 14 | عدد الشموع لحساب RSI |
| `oversold` | 30 | مستوى التشبع البيعي (دخول) |
| `overbought` | 70 | مستوى الخروج. جرّب 50–60 لخروج أسرع |

## متى بتنجح؟
- بالسوق **العرضي** أو الصاعد بهدوء: بتشتري القيعان الصغيرة وبتبيع القمم.
- نسبة الربح (Win%) عادةً عالية.

## متى بتفشل؟
- بالسوق **الهابط بقوة**: RSI بيضل تحت 30 وبيرتد شوي وبيرجع ينزل → "التقاط سكين نازلة".
- الخسارة الوحدة ممكن تمحي أرباح صفقات كثيرة → **لازم stop loss**.
- بالسوق الصاعد القوي ممكن تطلع بدري وتفوّت الصعود.

## إدارة المخاطر المقترحة
`stop_loss_pct: 5` (مفعّل بالإعدادات الافتراضية) — ضروري لهاي الاستراتيجية.

## مثال إعدادات
```yaml
- name: rsi_reversion_14
  strategy: rsi_reversion
  params: {period: 14, oversold: 30, overbought: 70}
  stop_loss_pct: 5
```
